How this keeps you safer than “anti-detect” exes

  • ✅ 100% open source — every line is in this repo. No hidden exe updates.
  • ✅ No telemetry, no accounts, no tokens needed. Works fully offline.
  • ✅ No remote-debugging flags — websites cannot drive your logged-in tabs.
  • ✅ Local API is locked — 127.0.0.1 only + random per-run token + no CORS.
  • ✅ Proxy passwords encrypted on your disk (never plaintext).

Quick start

  1. Create one profile per YouTube channel / Facebook page. Pick Desktop or Mobile fingerprint.
  2. Press Launch, log in once inside that profile window. Sessions stay separated.
  3. Optional proxy per profile: custom (tested above), free pool, or a GitHub tunnel from your own throwaway accounts (Proxies tab). Direct connection is safest for important logins.
  4. For posting/uploading, prefer the official APIs — see automation/README.md.

Honest note about “undetectable”

No tool can promise Facebook/YouTube will never detect automation. What actually works: consistent fingerprint per profile, clean IP, human pacing, real activity history, and official APIs for uploads/posts. Anyone promising invisibility is lying.
